Detailed Description

Tests that pin the matching contract: price-time priority, no crossed book, each order type, cancel and modify.

The data-driven suite in test.cpp only checks order and level counts, so it cannot tell a correctly ordered book from one with the bid/ask comparators reversed. Every test here checks which resting order traded, at which price, and in which order.
